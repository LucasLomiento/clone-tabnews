suas páginas.

```json
{
  "name": "Clone TabNews",
  "navigation": {
    "tabs": [
      {
        "tab": "Documentação",
        "pages": [
          "index",
          { "group": "Começando", "pages": ["comecando/instalacao", "comecando/primeiros-passos"] }
        ]
      }
    ]
  }
}
```

## As regras

- Cada item de `pages` é o caminho do arquivo **sem a extensão**, a partir de `docs/`.
- Um item pode ser um grupo: um objeto com `group` (o nome no menu) e as `pages` dele.
- A ordem da lista é a ordem do menu.
- Página que não está no menu continua publicada, mas só é achada por link.
