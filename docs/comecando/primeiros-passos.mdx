## Editando uma página

1. Abra um arquivo `.mdx` dentro de `docs/`.
2. Mude o texto e faça o commit na branch `main`.
3. Envie com `git push`.

Em poucos instantes, o WriteDocs sincroniza o repositório e publica o site de novo. O andamento aparece
em **Deployments**, no dashboard, com o log do build ao vivo.

## Editando pelo dashboard

As mudanças feitas no editor do WriteDocs viram commits neste repositório. Os dois caminhos ficam em
sincronia, nos dois sentidos.
