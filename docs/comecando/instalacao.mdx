## Requisitos

- Node.js 22 ou mais novo
- npm

## Passo a passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/LucasLomiento/clone-tabnews.git
   cd clone-tabnews
   ```

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Siga para os [primeiros passos](/comecando/primeiros-passos).
